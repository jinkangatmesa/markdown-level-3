# Command-Line Cheat Sheet

> ## Basic/Common Command-Line Commands:

**Command:**     **Action:**

1. mkdir < > - Creates new folder; can name the folder anything

- Example of the mkdir command: 

mkdir apple1

---

2. pwd < > - Shows current directory/*Uses to see your current location*

- Example of the pwd command:

pwd

Output: /workspaces/apple1

---

3. ls < > - Lists diectory files

- Example of ls command:

ls 

Output: folder1 file.md file2.txt

---

4. cd < > - Changes directory

- Example of the cd command:

cd apple1

---

5. cd .. < > - Go back a directory

- Example of the cd .. command :

cd ..

---

6. touch < > - Creates empty file/*Like as .md and .txt inside of a folder* 

- Example of the touch command :

cd apple1

touch file.md

touch file2.txt

---

> ## Notice:

- Add a space between the command and < > or it won't work
- Use the pwd command to locate your location before running any commands
- " < > " is a placeholder for your file and folder
